📲 添加到 iPhone / iPad 主屏幕像普通 App 一样打开实验室 ›
  1. 老师将这一个 index.html 文件上传至 GitHub Pages（只需要操作一次）。
  2. 把生成的网页链接发给学生家长，在 iPhone 的 Safari 打开即可互动操作。
  3. 需要固定在手机桌面时，点击 Safari「共享」→「添加到主屏幕」。
  4. 如显示「作为网页 App 打开」，打开这个选项，然后点击「添加」。

请注意：iPhone「文件」App 的 HTML 预览可能无法运行交互脚本；请通过网页链接打开。此单文件版不包含离线缓存服务，首次使用及重新打开网页时通常需要网络。
